# Expression Detector: frontend

Next.js (App Router, TypeScript, Tailwind CSS) client for the Expression Detector.

```bash
npm install
cp .env.example .env.local   # optional, only if the backend isn't at http://localhost:8000
npm run dev                  # http://localhost:3000
```

See the [main README](../README.md) for full setup, including the FastAPI backend.
